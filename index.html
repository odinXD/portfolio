ROS 2 로봇팔 제어

대표 프로젝트 · 팀 실습 · Python, ROS 2, Jetson

게임패드로 로봇팔 끝의 위치를 조작하고, 목표에 맞게 움직였는지 관절 측정값으로 확인하는 실습입니다.

내가 맡은 부분
게임패드 입력을 손끝 목표로 바꾸는 노드와 역기구학(IK) 노드의 토픽 연결을 완성했습니다. 두 노드를 게임패드 드라이버와 함께 띄울 수 있도록 Launch 설정에 실행 노드와 인자를 연결했습니다.
실제 장비에서 확인한 것
관절 제어 실습에서 어깨 관절에 0.5 rad를 요청했을 때 측정값이 목표를 따라가는 것을 확인했습니다. 허용 범위를 벗어난 요청은 제어기에서 거부됐고, 로봇팔은 이전에 수락한 자세를 유지했습니다.
로그를 볼 때 놓치기 쉬운 점
그래프에서 /joint_targets로 그린 선에는 제어기가 거부한 요청도 남습니다. 실제 관절이 움직였는지는 /joint_states로 받은 측정값을 봐야 알 수 있습니다.

관련 실습

PC와 Jetson 사이의 관절값 조회

Jetson에서 발행한 관절값을 PC에서 구독하고, 서비스로 마지막 수신값을 조회하는 구조를 구성했습니다. Python 클라이언트와 ROS 2 CLI 양쪽에서 응답을 확인했습니다.

MuJoCo에서 로봇팔 환경 검증

Gymnasium 환경에서 팔 끝과 두 큐브의 위치를 관측값으로 연결했습니다. 무작위 행동을 세 회차 실행해 관측값과 보상이 갱신되고, 각 회차가 150스텝에서 시간 제한으로 끝나는 것을 확인했습니다.

로봇팔 응답 비교 도구

같은 목표를 준 실제 로봇팔과 MuJoCo 모델의 관절 로그를 비교하는 도구를 만들고 싶습니다. 우선 CSV 두 개를 읽어 명령 시점을 맞추고, 관절별 각도 오차와 응답 지연을 그래프로 보여주는 것부터 시작할 계획입니다.
